## What's new

- **QR codes and barcodes:** Text mode (`T`) now reads codes with ZXing.Net. A card shows each code's content, with **Copy** and, for links, **Open**.
- **Font preview:** TTF, OTF, TTC and OTC files now have a dedicated sheet with the alphabet, samples at increasing sizes and a character grid. Click a character to copy it. Fonts are read from a temporary copy so the original file remains available to rename or delete.
- **Keyboard Open with:** The app menu opens in the middle of the preview. Use the arrow keys to select an app (the default app comes first), then `Enter` to open it.
- **Copy file path:** `Ctrl+Shift+C` copies the file's path.
- **Colour formats:** The pipette copies HEX with `Ctrl+click`, CSS `rgb()` with `Ctrl+Shift+click`, and CSS `hsl()` with `Ctrl+Alt+click`.
- The shortcuts card and the Open with menu now close when the preview window is moved or resized.
