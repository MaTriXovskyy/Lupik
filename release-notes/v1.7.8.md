## Quick previews in Windows file pickers

- Select a file in a standard Windows Open or Save dialog and press the preview key (Space by default) to open Lupik. Close the preview to return to the file picker without accepting the dialog.
- Preview follows the selected item in that dialog, including filenames with spaces, Unicode characters and hidden extensions. It never falls back to a file selected in a different Explorer window when a dialog selection cannot be resolved.
- Space keeps its normal behavior in filename, search and rename fields, on dialog buttons and in message boxes.
- Reading the dialog selection runs in the background, so it cannot block the global keyboard hook or Lupik's interface.
- File-picker controls are prepared in advance, keeping repeated previews responsive. The preview key tracks physical presses and releases so one press closes the preview after a focus change, while holding the key does not repeatedly open and close it.
- Faster first previews: prepare the Explorer connection during idle startup, reuse file-type icons and stop waiting for a cached thumbnail once the actual image is ready.
