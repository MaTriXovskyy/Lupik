## Changes

### Normal window behavior

- A newly opened preview is brought to the front once, then behaves like a normal window. Other applications can cover it, independently of whether Explorer is minimized.
- Clicking a preview gives it normal keyboard focus. Search and preview shortcuts work in both ordinary and pinned windows.
- Pinned windows retain their optional always-on-top toggle.

### Release preview resources immediately

- Closing a preview immediately releases its document, images, preloaded images and other viewer resources instead of waiting 15 seconds.
- Audio and video play from a temporary copy so Windows' asynchronous media decoder cannot keep the original file locked. Large media files take longer to open and need temporary disk space.
- Closing no longer forces full garbage collections, waits for unrelated finalizers or trims the process working set on the UI thread.
- Cancelled background loads cannot reopen a closed preview.

### Protect unsaved edits

- Editors, navigation and closing are guarded while a save is in progress.
- Failed saves retain unsaved changes. Text is marked saved only when it matches the snapshot written to disk.
- System Close and Alt+F4 use the save/discard/cancel prompt. Choosing Save completes the write before closing or navigating away.
- Edited PDF pages remain available if saving fails, until a successful save and reload.

### Validation

- Added Windows regression checks for file access after closing, background-load cancellation, window ordering and activation, editing and saving, close prompts, PDF persistence and nonblocking resource cleanup.
